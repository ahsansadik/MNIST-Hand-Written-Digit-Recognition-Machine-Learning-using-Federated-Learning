# MNIST-Hand-Written-Digit-Recognition-Machine-Learning-using-Federated-Learning
Privacy-preserving Federated Learning sandbox in PyTorch using Federated Averaging (FedAvg) across non-IID MNIST sub-systems (0–2, 3–6, 7–9) with a central aggregator. Tracks per-round accuracy, unseen-class transfer, and multi-round convergence on local GPU hardware as a baseline for distributed health informatics.
